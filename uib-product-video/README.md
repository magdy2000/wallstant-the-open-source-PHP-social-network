# UIB Product Video (Remotion)

A ~21s, 1920×1080 promo for the UIB waterproofing membrane + Primer D41, built from the site footage.

Scenes: Intro (logo) → close-up of the roll → membrane + primer system → on-site installation with features → finished roof → outro with contact details.

- Final renders: `renders/UIB-Promo.mp4` (16:9) and `renders/UIB-Promo-9x16.mp4` (9:16 for Instagram Reels / TikTok)
- Source footage: `public/footage.mp4` (re-encoded to 30 fps)
- Music bed: `public/music.wav`, generated by `python3 scripts/make-music.py public/music.wav 21.2 16.5`
- Font: Cairo (SIL OFL), bundled in `public/fonts`
- Texts and timing: `src/scenes/*.tsx`, durations in `src/theme.ts`

## Commands

```bash
npm i
npx remotion studio          # preview / edit
npx remotion render UibPromo out/UIB-Promo.mp4 --crf=18
npx remotion render UibPromoVertical out/UIB-Promo-9x16.mp4 --crf=18
```

In a sandbox without Chrome download access, set `REMOTION_BROWSER` to a local headless Chromium binary.
